# Design language — latest comparisons

- **Tone/density:** technical benchmark report; intentionally dense, for scanning many workloads.
- **Canvas/type:** white SVG canvas; Arial sans-serif with compact labels and bold section headings.
- **Palette:** existing dark blue-green ink, pale blue-gray headers and section bands, alternating white/near-white rows, blue faster and orange/red slower score fills.
- **Geometry:** sharp, full-width matrix with four aligned comparison columns; small rounded score cells are an established local convention.
- **Evidence:** before screenshot `evidence/screenshots/before/desktop.png` and neighboring generated SVG source `docs/images/performance-latest-build-comparison.svg`.
- **Must preserve:** four directional pairings, current suite/size/case order, color semantics, historical `1.8.0.0` chart separation, and `2.2.1.0` flavor-specific baseline labels.
- **Do not introduce:** new palette, card system, gradients, shadows, decorative icons, or a second recent-reference graphic.
