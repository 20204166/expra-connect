# Design language — performance index plots

- **Tone:** technical benchmark visualization with compact, data-dense panels.
- **Type/canvas:** white SVG canvas, Arial sans-serif, dark blue-green ink, understated small axis ticks.
- **Chart language:** horizontal point-index plots; 100.000p is the baseline marker, colored point series reuse release colors, and muted vertical guides aid reading.
- **Change constraint:** extend only the horizontal index domain; do not change measured values, series colors, panel geometry, or baseline semantics.
